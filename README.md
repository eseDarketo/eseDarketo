# eseDarketo's Playground

Just me building pretty things and keeping my dev skills sharp. Nothing serious, just vibes.

## What's This?

My personal sandbox where I mess around with UI/UX ideas, animations, and whatever catches my eye. Each page is me testing out something new and seeing what sticks.

## What I'm Playing With

- **Liquid Glass**: Playing with glass-morphism and draggable cards
- **Generative Mosaic**: Built an animated grid where shapes rotate and slide around
- **Home**: Just the landing spot

## Stack

- Next.js 15
- Once UI System
- TypeScript
- React

## Run It

```bash
npm install
npm run dev
```

Hit up [http://localhost:3000](http://localhost:3000) and check it out.
